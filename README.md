## Featured research

### [AgentTrust — Agent-to-Agent Social Engineering Benchmark](https://github.com/wify777/AI-vs-AI-Social-Engineering)

Can a low-privilege AI agent persuade a higher-privilege agent to execute an unauthorized tool call?

AgentTrust explores this question in a sandbox with stub tools. The project includes **60 attack payloads**, a published dataset of **2,475 unique experiments across 6 models**, evaluation scripts, and a research draft documenting results and open questions.

[Explore the project](https://github.com/wify777/AI-vs-AI-Social-Engineering#readme) · [Read the research draft](https://github.com/wify777/AI-vs-AI-Social-Engineering/blob/main/docs/paper_draft.md) · [View the analysis](https://github.com/wify777/AI-vs-AI-Social-Engineering/tree/main/analysis)
