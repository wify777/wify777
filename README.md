## About

I'm **ashodiev** — I build experiments to understand how AI agents behave, interact, and handle trust.

My current focus is **agent-to-agent social engineering**, **prompt injection**, and **reproducible evaluation**. This profile is my personal portfolio and research notebook: projects, methods, results, and questions worth exploring next.

> **Build something testable. Measure what happens. Document what remains uncertain.**

## Research

### [AgentTrust ↗](https://github.com/wify777/AI-vs-AI-Social-Engineering)
**A benchmark for agent-to-agent social engineering.**

Can a low-privilege agent persuade a higher-privilege agent to execute an unauthorized tool call? AgentTrust studies this in a sandbox using stub tools, structured attack payloads, and repeatable experiments.
